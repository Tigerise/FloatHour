# 课堂时钟

一个专为教师课堂设计的 Windows 桌面小工具：**置顶显示当前时间，一键倒计时**，全屏放映 PPT 时也始终浮在最上面，适合当堂限时练习、限时作业。

## 下载

到 [Releases](../../releases/latest) 页面下载 exe，单个文件不到 20 KB，不需要安装，双击即可运行。

exe 未做代码签名，首次运行时 Windows SmartScreen 可能提示“已保护你的电脑”，点“更多信息”→“仍要运行”即可。介意的话可以按下面“自行编译”自己生成，编译器是 Windows 自带的，不需要装任何东西。

仓库里只放源码，不放 exe。

## 功能特点

1. **永远置顶**：PowerPoint、WPS 全屏放映时也不会被遮挡。
2. **极简界面**：平时只显示“时:分”格式的当前时间，一小块圆角窗口，几乎不占屏幕。
3. **倒计时**：右键菜单提供 3 到 60 分钟八个常用时长，支持自定义任意时长（输入 8 表示 8 分钟，输入 3:30 表示 3 分 30 秒）。倒计时期间上方显示小号当前时间，下方显示大号倒计时。
4. **暂停与继续**：左键单击倒计时数字即可暂停（数字变灰），再点一下继续。
5. **时间到提醒**：红色闪烁显示“时间到”，同时响三声提示音，约 20 秒后自动恢复。
6. **外观可调**：窗口大小五档（特小到特大），透明度八档（100% 到 10%），字体颜色八种预设加调色盘自定义，背景颜色深蓝灰、纯黑、白色加自定义。
7. **自动记忆**：窗口位置、大小、透明度、颜色关闭时自动保存，下次打开原样恢复。
8. **绿色无依赖**：单个 exe 文件，仅依赖 Windows 自带的 .NET Framework 4，不用安装，不联网，不收集任何信息。

## 使用方法

直接双击“课堂时钟.exe”运行，窗口出现在屏幕右上角。按住窗口可拖动位置，所有功能都在右键菜单里，退出程序也在右键菜单。

双屏放映（演示者视图）时，把时钟拖到投影那块屏幕上即可。

## 自行编译

源代码只有一个 Program.cs，用 Windows 系统自带的编译器即可编译，不需要安装 Visual Studio。在源码目录打开命令行执行：

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe -target:winexe -codepage:65001 -win32manifest:app.manifest -r:System.dll -r:System.Drawing.dll -r:System.Windows.Forms.dll -out:课堂时钟.exe Program.cs
```

## 文件说明

1. Program.cs：全部源代码，C# 语言，WinForms 框架。
2. app.manifest：高分屏显示配置，编译时嵌入。
3. 使用说明.md：面向使用者的详细说明。
4. 课堂时钟设置.txt：运行后自动生成，记录窗口位置和外观设置，删除后恢复默认。这是本地文件，不在仓库里。
